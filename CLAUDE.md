# Cyberpunk RED system

The contributor and LLM conventions for this repository — the rules, the full
`STYLE_GUIDE.md`, and the entire mechanics catalog — are maintained in the shared
[`cpr-llm-rules`](https://gitlab.com/cyberpunk-red-team/cpr-llm-rules) repository
and vendored into `.cprc-shared/` via `git subtree`. **Edit them there, not here**;
update the local copy with
`git subtree pull --prefix=.cprc-shared <cpr-llm-rules> main --squash`.
