# Actor: Borg / Full Body Conversion

- **Full Body Conversion (Borg / "Going Metal")** (*Going Metal*, Interface RED Vol 3) — the meat brain becomes a
  **Biosystem** (Borgware, hardened vs EMP, radiation-immune) inhabiting an interchangeable **FBC body** (a chrome
  package built on an Internal Linear Frame). INT/COOL/TECH/WILL/LUCK/EMP & Skills carry over; **BODY/HP/Death
  Save = the body**, **REF/DEX/MOVE = its cyberware**. Foundational FBC chrome is **0-HL and doesn't depress max
  Humanity**, option slots are **doubled**, and the Grafted-Muscle strength prereq is auto-met. Damage hits the
  body (Biosystem un-targetable while installed); **immune** to most physical Crit effects + bonus damage, all
  Wound-State penalties (Death Saves still apply), disease/poison/drugs (unless Airhypo'd to the access port),
  radiation, and fire (with a coating); needs monthly Glucose Solution (miss → −2; two misses → death) and sleep;
  Cryo/Speedheal don't work — repair is DV15 Cybertech / 4h to full (self-ok). **Body-swap** = DV17
  Cybertech/Surgery / 4h (re-pay HL for the new body's chrome); only the inhabited body's chrome counts toward
  max-Humanity depression. A Tech can build a body (DV29 Cybertech; not from medical-grade parts). Internal Linear
  Frame Omega = BODY 16 (changes HP/Death Save, 2 Borgware); Internal Hydraulics sets REF/DEX/MOVE to a 4/6/8
  floor. Otherwise a Borg follows the normal **Character** rules (Roles, LUCK, IP, checks, conditions) — see
  [character.md](character.md).
