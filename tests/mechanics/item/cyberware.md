# Item: Cyberware

## Cyberware

- **Humanity Loss** — preset vs rolled; first-install-only for Chipware/Cyberlimbs; max-Humanity reduction (−2/−4);
  0-HL (see Humanity section) (Core, p.111).
- **Option Slots** — a foundational piece grants slots (Neural Link 5, Cybereye 3, Cyberaudio Suite 3, Cyberarm 4,
  Cyberleg 3); options cost 1/2/3; non-foundational categories (Fashionware/Internal/External) have a 7-slot cap;
  same-item benefits don't stack (Core, p.111).
- **Slot expanders** — MultiOptic (+5 eyes), Sensor Array (+5 audio), Chipware Compartment, Modular Finger (8
  fingers), Artificial Shoulder (+2 arms), Cyberdeck-arm (+1 deck slot), FBC (doubles); slot-cost reductions
  (Optimized Popup 0-slot, Double Chip, *Invented Tech Upgrades*) (Core, p.116).
- **Install** — tier Mall/Clinic/Hospital; paired options (buy twice, install in two eyes/legs, pay HL each);
  prerequisites (Neural Link → Neuralware; Neuroport → 2070s chrome); wearable cyberware (no surgery/HL,
  Interface-Plug connect); can't install while suffering a related Critical Injury; a paired cyberlimb counts as
  one item for Cost/HL but separately for Critical Injuries & repair (*12 Days of Cybermas*); some options install
  as the **only** cyberware in a meat arm/leg, overriding the cyberlimb-host requirement (Big Knucks et al., Core,
  p.364) (Core, p.110).
- **Speedware** — only one installed; Initiative bonus (Kerenzikov passive / Sandevistan active / David's
  extra-action) (Core, p.112).
- **Capability flags** — wound-state ignore (Pain Editor/Berserk); stat set/boost; skill chip (Level 3) / +N skill;
  weapon-granting (Mantis/Monowire/Gorilla/Gun-Hand/etc.); EMP & Crit immunity (Hardened/Cyberspine/Cyberskull;
  per-limb Broken-Arm/Leg immunity via Reinforced Cyberlimb, *Black Chrome*);
  drug auto-inject; detection/control (Cyberscanner, Drone Remote, jammers); dodge-bullets-regardless-of-REF
  (Reflex Co-Processor); Quickhacks via Neuroport (Core); feign-death state (DeathTrance, *12 Days of Cybermas*);
  choke→knockout alternative (Gang Jazzler); 0-slot sponsored covering with monthly income (*Must-Have Cyberware
  Deals*).
- **Enhancements (2077)** — off-the-rack cyberware upgrade; one per piece, body-implanted only, type-specific,
  Tech-installs with no Check, not a Maker Upgrade; effects widen weapon params (extra crit rolls, ignore-armor-
  below-SP7, +ablation, combination mode, non-lethal) (*Cyberware Enhancements*).
