# Elflines Online — base game

- **Elflines Online — base game** (Interface RED Vol 1) — an in-fiction MMO subsystem: own chargen (50 STAT / 60
  Skill, no LUCK), Ranks 0–10, gp economy + 1eb:100gp pay-to-win; **ranged attacks dodgeable by default**;
  out-of-combat heal to full in 1 min; death = teleport to camp + revive tax; **Miasma** (everywhere outside
  cities/camps) blocks elven fast-heal/Treatment and enables PvP; cross-layer actions use the RED character's
  skills.
